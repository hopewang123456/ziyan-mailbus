ziyan-mailbus v2.0 — 消息总线架构规划

新增模块: 任务追踪 · 心跳检测 · 催办 · 错误回执 · 优先级抢占 · 消息检索

消息协议

  • • type: notice / task / task_reply / question / forward / broadcast
  • • action: {ack, reply, execute, forward_to, store_memory}
  • • task: {summary, assignee, status, deadline, deliverable}
  • • forward_chain: 多跳追踪（灵曦→小七→一哥）
  • • id 幂等: 重复推送自动去重

任务 + 错误回执

  • • 看板: pending → running → success / failed / timeout
  • • 错误回执: {error_code, reason, trace, failed_at}
  • • 催办: 超时后自动重推 + 升级通知给调度者
  • • 优先级: urgent 抢占 normal，被抢占者收到暂停通知

运维

  • • 心跳: 定时 ping Agent CLI，状态实时更新到看板
  • • 检索: SQLite FTS5，按 from/to/content/time 搜索
  • • 看板: Web 页面，任务链路可视化 + 在线指示灯
  • • mailbus search: CLI 全文搜索命令
