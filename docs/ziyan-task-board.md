# 子言全局任务看板方案

> 子言打开 Dashboard，一眼能看到所有任务的执行状态。

---

## 目标

子言不需要翻 inbox、不需要问任何人，打开面板就能回答：
- 我发的任务现在到谁手上了？
- 每一步用了多久？
- 是卡住了还是在正常推进？
- 每一步的报告是什么？

---

## 看板位置

在子言面板（现有 tab）中新增「📋 我的任务」区域，放在待确认事项下方。

---

## 展示内容

### 任务卡片

每条任务一张卡片，展示完整的流转路径 + 当前状态：

```
┌────────────────────────────────────────────────────────────┐
│ 📋 Dashboard 重设计                         发起的 25 分钟前 │
│                                                             │
│  发起 → 小七 → 大力 → 灵鉴 ⏳                               │
│                         ↑ 等待灵鉴审查 (已等 5 分钟)        │
│                                                             │
│  步骤: 3/4 · 审查中                                         │
│  SLA: 审查还剩 10 分钟 · 超时催办 0/3                       │
│                                                             │
│  ┌─ 查看各步骤报告 ──────────────────────────────────┐     │
│  │  ✅ ① 灵昭派发 → dispatch-report         查看 →  │     │
│  │  ✅ ② 大力开发 → dev-report             查看 →  │     │
│  │  ⏳ ③ 灵鉴审查 → (等待中)                         │     │
│  │  ⏸ ④ 灵验测试 → (排队中)                         │     │
│  └─────────────────────────────────────────────────┘     │
└────────────────────────────────────────────────────────────┘
```

### 分类展示

| 分区 | 颜色 | 内容 |
|------|------|------|
| 🔴 异常 | 红色 | 超时的、失败的、跳过步骤的 |
| 🟢 进行中 | 绿色 | 正常流转中、SLA 内 |
| 🟡 排队中 | 金色 | 因并发上限在等待的 |
| ⚪ 已完成 | 灰色 | 最近 24h 完成的（可折叠） |

### 过滤

顶部有过滤选项：
- [全部] [我发起的] [我关注的] [异常]
- 默认显示「我发起的 + 异常」

---

## 数据来源

| 数据 | 来源 |
|------|------|
| 我发起的任务 | `GET /api/tasks?initiator=ziyan` |
| 所有 running 任务 | `GET /api/tasks?status=running` |
| 流转路径 | 任务链 `chain[]` 的 from_person → to_person |
| 当前步骤 | `chain[-1]` |
| 耗时 | `chain[0].started_at` → now |
| 各步骤报告 | `chain[step].report` |
| SLA 状态 | `chain[-1].started_at` + 角色 SLA 标准 |
