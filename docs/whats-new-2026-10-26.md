# 今日功能导览 · 2026-10-26（AI 助手知识库 + 审阅导览双用）

今天一次落地了规划 P0~P5 六大阶段（十五决策 D1-D15）。按「你会用到什么」组织：

## 作为子言，你每天会碰到的三个入口

1. **⚡ 发令**（任意页面右下角）——指挥席位：选职位填表发令 / 写自由需求让 LLM 出草稿再确认；执行中卡住会在这里收到【待我处理】消息，点卡片上的「批准计划/验收/回退」直接响应。头部的 ✎ 可改你的显示名。
2. **🤖 助手**（发令按钮旁）——问系统状态（数字来自指标真值不会编）或操作方法（引 runbook 手册，带来源）。
3. **管理中心 `/console`**——逃生舱彻底重做：职位表单编辑（改完发令窗口立即生效）、agent 启停、告警规则阈值、指标大盘卡片开关、审计与诊所。

## 背后变了什么（架构一图流）

- **口径只有一个真源**：`shared/config/mailbus/metrics-manifest.json`——python/java 两套引擎各自计算但口径同源；改口径改 JSON，双栈生效，前端大盘自动多卡。
- **告警会主动找人**：`alert-rules.json` 规则触发 → 写告警 + 给子言发消息（30 分钟去抖），在管理中心改阈值即时生效。
- **配置型（L3）**：装配选择（audit/notifier 实现）进 config.json 的 composition 段；java 侧 Spring 条件装配（mailbus.ai.enabled=true + provider 即激活 AI）。
- **双栈 AI**：python 走 internal_llm（RAG 已建），java 走 Spring AI（OpenAI 兼容端点，deepseek/ollama 经 SPRING_AI_OPENAI_BASE_URL 切换）；同一份 docs/ 知识库。
