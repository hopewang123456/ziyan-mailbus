# 指挥席位（发令窗口）使用指南 · 2026-10-26

## 打开
任意页面右下角「⚡ 发令」按钮（双舱可用）。未读红徽标=有待我处理事项。

## 发起工单（两条路）
1. **选职位**：点职位芯片（绿数字=空闲候选数）→ 按 inputs schema 自动生成表单 → 填写 → 发令。系统按 pin>空闲优先>轮询派发给具体 agent。
2. **自由需求（LLM 草稿）**：不选职位，在文本框写需求 → 「生成草稿」→ 预览职位步骤链（可换职位/改理由/调序/删步）→ 「按草稿发令」。

## 被唤起与响应
- 「待我处理/待批/告警/新消息」标签的消息会出现在会话流（30s 轮询）。
- 待批消息卡上有「批准计划/验收/回退/继续」按钮，一键执行工单 FSM 动作。
- 头部 ✎ 可改子言显示名（身份 ID 不变）。

## 常见问题
- LLM 草稿生成失败 → 检查 internal_llm 配置（ollama/deepseek）是否可达；显式报错不静默。
- 职位无表单 → 该职位在 role-types.json 未配 inputs，走自由需求路径。
