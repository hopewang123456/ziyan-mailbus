## 五、优先级排序建议

```
第一批（P0 阻塞）:
  1. 任务流水线引擎（开发→审查→测试→上线自动化）
  2. Agent 权限不保存（P0 Bug）
  3. API Key 继承（P0 Bug）

第二批（P1 严重 Bug + 功能）:
  4. Token 统计（P1 功能）
  5. 灵巡巡检记录展示（P1 功能）
  6. 消息串行队列（P1 Bug）
  7. auto-ack 根治方案（灵霄/大力/小七）
  8. 灵鉴只ACK不执行（chat -q 优化）
  9. 历史消息淹没新任务（状态细化+inbox过滤）

第三批（P2 优化）:
  10. Dashboard 视觉重做（星空/赛博/毛玻璃/炫光）
  11. 审查记录/告警记录完善
  12. i18n 配置
  13. 子言专属 log
  14. 消息趋势图改折线
  15. 按钮布局优化
```
