# 角色流转规则

> 按工种（角色）定义，不按人名。
> 每个工种完成任务后，mailbus 根据结论自动决定下一步派给谁。
> agent 只需要填 conclusion，不需要知道下一步给谁。

## 按角色的流转规则

### 方案设计师

| 场景 | 结论 | to | 说明 |
|------|------|----|------|
| 方案设计完成，需要开发 | approved | 调度员 | 方案通过→调度员安排开发 |
| 方案设计完成，仅需审查 | approved | 审查官 | 不需要开发，直接审查 |
| 收到子言需求 | received | (自己处理) | 先出方案 |
| 需要技术调研 | need_research | 技术研究员 | 先调研再决策 |
| 收到异常/阻塞 | notified | (处理) | 需要决策的问题 |

### 调度员

| 场景 | 结论 | to | 说明 |
|------|------|----|------|
| 需要编码实现 | dispatched | 开发工程师 | 派给主力开发 |
| 仅需审查 | dispatched | 审查官 | 不需要开发，直接审查 |
| 需要安全审计 | dispatched | 安全审计师 | 安全相关 |
| 需要运营执行 | dispatched | 运营 | 日常运营 |
| 收到测试报告，验收通过 | approved | (完成) | 任务结束 |
| 收到测试报告，验收不通过 | rejected | 开发工程师 | 退回重修 |

### 开发工程师

| 场景 | 结论 | to | 说明 |
|------|------|----|------|
| 开发完成，自测通过 | done | 审查官 | 提交审查 |
| 开发遇到阻塞 | blocked | 方案设计师 | 需要决策 |
| 紧急修复完成 | done | 测试工程师 | 直接给测试，跳过审查 |

### 审查官

| 场景 | 结论 | to | 说明 |
|------|------|----|------|

| 审查通过，改动较小 | pass | 验收员 | 小改动，验收兼测 |
| 审查不通过，需要重修 | fail | 开发工程师 | 退回重修 |

### 自动分配逻辑

```python
ROLE_MAP = {
    "方案设计师": ["lingzhao"],
    "调度员":    ["xiaoqi"],
    "开发工程师": ["lingxiao", "dali"],
    "审查官":    ["lingjian"],
    "测试工程师": ["lingyan"],
    "安全审计师": ["lingjin"],
    "技术研究员": ["lingxi"],
    "巡检官":    ["lingxun"],
    "运营":      ["yige"],
    "验收员":    ["xiaoqi"],
}

def pick_person_for_role(role):
    candidates = ROLE_MAP.get(role, [])
    for person in candidates:
        if is_online(person) and not is_busy(person):
            return person
    return candidates[0] if candidates else None
```

### 链节点数据结构（完整版）

```json
{
  "step": 3,
  "from_role": "开发工程师",
  "from_person": "dali",
  "to_role": "审查官",
  "to_person": null,
  "action": "开发完成",
  "report": {
    "template": "dev-report",
    "conclusion": "done",
    "summary": "配色+导航栏完成",
    "cc": ["方案设计师", "调度员"]
  },
  "status": "done",
  "started_at": "2026-06-04T10:02:00+0800",
  "completed_at": "2026-06-04T10:30:00+0800"
}
```

| 字段 | 说明 |
|------|------|
| from_role | 发件人角色（工种）|
| from_person | 发件人具体是谁 |
| to_role | 收件人角色（工种）|
| to_person | 收件人具体是谁（null=未分配，mailbus自动选）|
| report | 该步骤产出的工单（含 conclusion、cc 等）|
| status | pending / running / done / failed / skipped |
| started_at | 开始时间 |
| completed_at | 完成时间 |
