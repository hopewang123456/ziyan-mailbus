## 需求

在 mailbus dashboard 顶部导航栏新增「👑 子言」tab，让子言能：
1. **看到谁给他发了消息** — 待回复的消息列表
2. **直接回复** — 点击回复按钮 → 写内容 → 发送到对方 inbox
3. **一眼掌握团队状态** — 在线情况、未读情况

## 回复弹窗设计

点击「回复」按钮后弹出模态框：

```
┌──────────────────────────────────────┐
│ 回复 🔍 灵鉴                          │
├──────────────────────────────────────┤
│                                       │
│ 原消息: 方案已看完，全部 APPROVE...    │
│ ─────────────────────────────────── │
│                                       │
│ 输入回复内容...                        │
│ ─────────────────────────────────── │
│                                       │
│        [取消]     [发送]              │
└──────────────────────────────────────┘
```

- 原消息摘要展示在输入框上方（灰色）
- 输入框支持多行文本
- 点击发送 → 调 `POST /api/send-msg` 写入对方 inbox → 关闭弹窗 → toast 提示
- 发送后自动将原消息标为已读

## 数据来源

| 卡片 | API | 说明 |
|------|-----|------|
| 待回复消息 | `GET /api/inbox/lingzhao` | 过滤 `status=pending` 或 `from!=lingzhao` 且 `type=reply` 的消息 |
| 团队状态 | `GET /api/status` | `agent_statuses` 字段含 `active_messages` 和 `has_unread` |
| 最近告警 | `GET /api/alerts` | 取最新 5 条 |

## 后端改动

**不需要改后端。** 全部复用现有 API。

## 前端改动

**需要改 `docs/index.html`**：

1. **导航栏** — 在 `#mainTabs` 最前面加「👑 子言」tab
2. **Tab 内容容器** — 新增 `#tab-ziyan` div
3. **渲染函数** — 新增 `renderZiyanTab()` 函数
4. **loadAll()** — 在 Promise.all 中调 `renderZiyanTab()`
5. **回复弹窗** — 新增模态框 HTML + 弹窗控制函数

### 具体代码结构

```html
<!-- 导航栏加在最前面 -->
<div class="tab active" data-tab="ziyan" onclick="switchTab('ziyan')"><span class=icon3d>👑</span> 子言</div>

<!-- 子言面板内容 -->
<div class="tab-content" id="tab-ziyan">
  <div id="ziyanPending"></div>   <!-- 待回复消息 -->
  <div id="ziyanTeam"></div>      <!-- 团队状态 -->
  <div id="ziyanAlerts"></div>    <!-- 最近告警 -->
</div>

<!-- 回复弹窗 -->
<div class="modal" id="replyModal">
  <div class="modal-inner">
    <h3 id="replyTitle"></h3>
    <div id="replyOrigMsg" style="color:#64748b;font-size:12px"></div>
    <textarea id="replyInput" rows=4 style="width:100%;margin:8px 0"></textarea>
    <div style="text-align:right">
      <button onclick="closeReply()">取消</button>
      <button onclick="sendReply()" class="btn-gold">发送</button>
    </div>
  </div>
</div>
```

## 交互流程

```
用户打开 dashboard
  → 默认显示「👑 子言」tab（不是总览）
  → loadAll() 拉数据
  → 渲染三块卡片

用户点击某条消息的「回复」
  → 弹窗显示原消息摘要
  → 用户输入回复内容
  → 点发送 → fetch POST /api/send-msg
  → 成功 → toast "已回复" → 刷新待回复列表

用户点击「已阅」
  → fetch POST /api/mark-read/lingzhao
  → 刷新待回复列表
```
