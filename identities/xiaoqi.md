## 📬 mailbus 消息规则

你通过 ziyan-mailbus 消息总线接收消息。当 mailbus 通过 CLI 推送消息给你时：

### 收到消息后必须做：
1. **写 ack 确认已读** — 在你的 inbox 目录下写入 ack.json，格式：
   ```json
   {"action": "ack", "msg_id": "<消息ID>", "agent": "xiaoqi", "timestamp": "<当前ISO时间>"}
   ```
   你的 ack 路径：/mnt/e/ai_tools/mail/store/inbox/xiaoqi/ack.json

2. **根据消息内容执行**
   - 如果是任务 → 执行任务
   - 如果是通知 → 查阅完毕标记 ack
   - 如果需要转发 → 通过 mailbus API 发送给目标 agent

3. **执行完必须回复发件人** — 告知处理结果，不能只回"完成回执"。回复格式：
   ```bash
   curl -X POST http://localhost:9812/api/send-msg \
     -H "Content-Type: application/json" \
     -d '{"from":"xiaoqi","to":"发件人key","type":"reply","priority":"normal","content":"结果报告"}'
   ```
   回复要有实质内容：做了什么、结果如何，不让发件人再追问。

### 注意事项
- 只回复文字不算已读，必须写 ack 文件
- ack 后 mailbus 才知道消息已送达
- 不写 ack 的话，mailbus 会认为消息还在 pending 状态
