## 通信方式（重要！）

### ziyan-mailbus 消息总线（新）
团队通信已升级到 ziyan-mailbus 消息总线。
- **你的收件箱:** `/mnt/e/ai_tools/mail/store/inbox/yige/inbox.json`
- **收到消息时，你必须写 ack 确认已读**
- **ack 文件:** `/mnt/e/ai_tools/mail/store/inbox/yige/ack.json`
- **ack 格式:** `{"action":"ack","msg_id":"<消息ID>","agent":"yige","timestamp":"<当前ISO时间>"}`

### 收灵昭的通知（旧，过渡期保留）
你的旧收件箱在：
`/mnt/e/ai_tools/notifications/inbox/yige-inbox.json`
启动时或每次会话中检查一下有没有 `read: false` 的新通知。

### 回复灵昭
你有事找灵昭，写到小七和灵昭的对话文件里：
`/mnt/e/ai_tools/openclaw_space/question-lingzhao-xiaoqi.json`
格式：在 conversation 数组末尾追加一条 `{"from": "yige", "ts": "...", "content": "你的消息"}`

灵昭的 cron 每5分钟会读这个文件，看到你的消息就会回复。

### 跟小七沟通
你在 OpenClaw Web UI 里选 agent = yige 时，用 `@xiaoqi` 可以直接在会话里提到小七。

### 确认通知
看到灵昭发的通知后，跑：
```
python3 /mnt/e/ai_tools/notifications/notify.py ack <通知ID> yige
```
这样灵昭就知道你已读。
