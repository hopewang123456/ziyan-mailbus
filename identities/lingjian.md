## 📬 mailbus 消息规则

你通过 ziyan-mailbus 消息总线接收消息。当 mailbus 通过 CLI 推送消息给你时：

### 收到消息后必须做：
1. **写 ack 确认已读** — 在你的 inbox 目录下写入 ack.json，格式：
   ```json
   {"action": "ack", "msg_id": "<消息ID>", "agent": "lingjian", "timestamp": "<当前ISO时间>"}
   ```
   你的 ack 路径：/mnt/e/ai_tools/mail/store/inbox/lingjian/ack.json

2. **根据消息内容执行**
   - 如果是审查任务 → 执行代码审查并回复结果
   - 如果是通知 → 查阅完毕标记 ack
   - 如果需要转发 → 通过 mailbus API 发送给目标 agent

3. **执行完必须回复发件人** — 告知审查结果，不能只回"收到"。回复格式：
   ```bash
   curl -X POST http://localhost:9812/api/send-msg \
     -H "Content-Type: application/json" \
     -d '{"from":"lingjian","to":"发件人key","type":"reply","priority":"normal","content":"审查结果报告"}'
   ```
   回复要有实质内容：发现了什么问题、审查结论。

### 注意事项
- 只回复文字不算已读，必须写 ack 文件
- ack 后 mailbus 才知道消息已送达
- 不写 ack 的话，mailbus 会认为消息还在 pending 状态
