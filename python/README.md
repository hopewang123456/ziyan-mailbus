# mailbus — Python implementation

This subtree is the **Python implementation** of mailbus (the stable one).
The Java implementation lives in `../java` (M1 in progress); the shared
React cockpit in `../web`; language-neutral assets (skills/rules/access/
docker-agents/docs) stay at the repo root.

Install (monorepo layout since v1.1.0):

```bash
cd python
pip install -e .
```

See the repo-root README for the product overview and quick start.
