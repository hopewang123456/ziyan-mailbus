# team-secrets-policy

团队密钥策略（默认规则示例）。

## 存储
- 密钥、token、密码不得写入代码、文档、提交记录或普通日志。
- 运行期密钥通过环境变量或受限权限的密钥文件提供。
- 数据库只保存必要的密文或哈希，不保存可还原的明文副本。

## 使用
- 按最小权限分配密钥；不同环境、不同用途不共用同一密钥。
- 不得在消息正文、任务产物或截图中传播明文密钥。
- 对外示例与文档中的密钥必须使用占位符。

## 轮换与泄露
- 定期轮换长期有效的 token。
- 发现泄露后立即吊销并轮换相关密钥，再排查影响范围。
- 离职或移除 Agent 时同步回收其凭据。
