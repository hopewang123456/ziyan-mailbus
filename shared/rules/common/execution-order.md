# execution-order

任务执行顺序（默认规则示例）。

## 基本顺序
1. 确认调用者身份与权限，越权请求直接拒绝。
2. 读取任务目标、上下文与约束，不明确时返回 `needs_info`。
3. 检查依赖与前置条件，未满足时不要强行执行。
4. 执行任务；写操作保持幂等，避免重复提交造成副作用。
5. 回传结果与产物；失败时给出明确状态与原因。
6. 完成后续确认（ack），不要重复回传同一结果。

## 并发与重试
- 同一任务已有进行中的执行时，不重复启动相同执行。
- 重试前先确认上次执行是否已生效。
- 超时或异常不得伪报成功；需要人工处理时返回 `needs_human`。
